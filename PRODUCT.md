# ANA Academy — product notes

## Product
An Arabic-first, free and open-source learning site that teaches beginner networking. It contains nine lessons, original diagrams, quizzes, an interactive network simulator, saved progress and accounts backed by Supabase.

## Audience and promise
Arabic-speaking beginners, including learners with no prior networking background. Explain networking in plain Arabic, introduce English acronyms in context, and connect each idea to a diagram, a browser lab and a check for understanding.

## Preserve
- Existing lesson pages, curriculum, quiz and lab behavior, account flows, progress, admin surfaces, theme toggle and Supabase integration.
- RTL Arabic with readable Latin network acronyms; responsive layouts, keyboard focus and reduced-motion preferences.
- Static HTML, CSS and JavaScript architecture. Do not change database behavior or invent product claims.

## Evidence limits
The site contains nine lessons and a simulator. No verified learner counts, testimonials, external endorsements, or performance claims are present. Keep all proof factual.

## Safety and privacy
The lab is a local simulation. Practice advice should continue to mention networks the learner owns or has explicit permission to test. Do not expose student email addresses in the admin UI.
