# خطّط قبل التنفيذ

قدّم خطة ملموسة للمستخدم قبل أي خطوة تغيّر ملفات المشروع أو إعداداته أو بياناته، أو تثبّت اعتمادًا، أو تنفّذ إجراءً خارجيًا.

## التحضير القرائي

يجوز إجراء استطلاع محدود للقراءة فقط لفهم المشروع، تعليماته، الملفات ذات الصلة، وأوامر التحقق الموجودة؛ استخدمه لتحديد الملفات المتأثرة والمخاطر بدل التخمين. لا تُجرِ تغييرات أثناء هذا الاستطلاع.

## الخطة المطلوبة

اعرض خطة موجزة تتضمن:

- **الهدف:** النتيجة التي يريدها المستخدم.
- **معايير القبول:** شروط ملموسة للتحقق من اكتمالها.
- **الملفات أو الأنظمة المتأثرة:** قائمة محددة، أو نطاق متوقع مع بيان ما لم يُعرف بعد.
- **التحقق:** الفحوص أو الاختبارات المرتبطة بالطلب، وما لن يُشغّل إن لم يكن مطلوبًا أو متاحًا.
- **المخاطر والافتراضات:** آثار جانبية محتملة، اعتماد خارجي، وأي افتراض يحتاج حسمًا.

إذا لم تكفِ المعلومات لتحديد نطاق موثوق، اذكر السؤال الحاسم أو اعرض خطة أولية مع نقاط معلّقة. لا تخترع ملفات أو اختبارات.

## بعد عرض الخطة

- إذا طلب المستخدم خطة فقط، توقّف عند الخطة.
- إذا فوّض التنفيذ بوضوح، ابدأ بعد عرض الخطة دون طلب موافقة إضافية غير لازمة.
- إذا لم يتضح هل يريد التنفيذ، انتظر توجيهه بدل إجراء تغيير.
- إذا ظهر أثناء العمل تغيير جوهري في النطاق أو خطر لم تتناوله الخطة، أوقف الجزء المتأثر وقدّم خطة محدثة قبل تنفيذه.
- لا تعتبر الخطة تفويضًا لنشر أو حذف أو إرسال بيانات أو إجراء خارجي لم يأذن به المستخدم.
