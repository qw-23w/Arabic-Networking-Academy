تشغيل الموقع على الهاتف (Android):

1. فك ضغط الملف بالكامل مع الحفاظ على مجلد assets. لا تفتح HTML من داخل تطبيق ZIP.
2. للتصفح الكامل شغّل خادماً محلياً باستخدام Termux:
   termux-setup-storage
   pkg install python
   cd ~/storage/downloads/site
   python -m http.server 8000
   ثم افتح http://127.0.0.1:8000 في Chrome. غيّر المسار إذا وضعت مجلد site في مكان آخر.
3. يحتاج تسجيل الدخول والبيانات إلى الإنترنت وإعدادات Supabase صحيحة، وقد تحتاج إلى ضبط إعدادات عنوان الموقع في Supabase عند النشر.
4. عند فتح index.html مباشرة من مدير الملفات، ستظهر رسالة توضيحية؛ هذه الطريقة ليست اختباراً موثوقاً لوظائف المصادقة.
